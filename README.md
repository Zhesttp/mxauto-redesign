# MXauto redesign
Static responsive website. Publish directory: `dist`.

No dependencies or build step. Edit `dist/index.html`, `dist/style.css`, and `dist/app.js`.

GitHub Pages: select **GitHub Actions** under repository Settings → Pages. The included workflow publishes `dist` on pushes to `main`. No credentials belong in this repository.

The deployed Sites version is maintained separately; GitHub Pages becomes active only after creating the GitHub repository and enabling Pages.
